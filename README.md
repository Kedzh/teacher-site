# 🎓 Сайт педагога — Романова Алина Евгеньевна

Персональный сайт учителя физики МКОУ Иркутского МО «Усть-Кудинская СОШ».

## 📁 Структура проекта

```
Сайт педагога/
├── index.html              — Главная страница
├── about.html              — Обо мне
├── resources.html          — Методическая копилка
├── achievements.html       — Достижения
├── students.html           — Для учеников и родителей
├── blog.html               — Блог
├── contact.html            — Контакты
├── assets/
│   ├── css/
│   │   └── style.css       — Дизайн-система и стили
│   ├── js/
│   │   └── main.js         — Интерактивность
│   └── img/
│       ├── portrait.jpg    — Портрет педагога
│       ├── classroom.jpg   — Фото с учениками
│       ├── favicon.svg     — Иконка сайта
│       └── blog-*.svg      — Иллюстрации для блога
└── materials/              — PDF-материалы (конспекты, РП)
```

## 🚀 Как открыть сайт

1. **Локально**: Откройте `index.html` в браузере (двойной клик)
2. **Через сервер**: Запустите локальный сервер для корректной работы:
   ```bash
   # Python
   python -m http.server 8000
   
   # Или Node.js
   npx serve .
   ```
   Затем откройте http://localhost:8000

## ✏️ Как редактировать контент

### Изменить текст
- Откройте нужный HTML-файл в любом текстовом редакторе (VS Code, Notepad++)
- Найдите нужный текст и замените его
- Сохраните файл

### Заменить фотографии
- Замените файлы в `assets/img/`:
  - `portrait.jpg` — портрет (вертикальное фото, примерно 575×698)
  - `classroom.jpg` — фото с учениками (горизонтальное, примерно 958×882)
- Или обновите ссылки в HTML-файлах

### Добавить материалы
- Поместите PDF-файлы в папку `materials/`
- В `resources.html` добавьте карточку по образцу существующих
- Обновите ссылки на файлы

### Изменить контакты
- Найдите в HTML-файлах email, телефон, адрес
- Замените на актуальные данные

## 🎨 Настройка дизайна

Цвета, шрифты и размеры настраиваются в начале файла `assets/css/style.css` в разделе `:root`:

```css
:root {
  --primary: #1e40af;        /* Основной синий цвет */
  --accent: #f59e0b;         /* Акцентный янтарный */
  --text-dark: #1f2937;      /* Цвет текста */
  --bg-light: #f8fafc;       /* Светлый фон */
  /* ... */
}
```
